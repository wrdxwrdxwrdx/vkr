## Реализация пакета параметрического оценивания для библиотеки pysatl-core

Работа посвящена развитию ранее разработанного прототипа модуля оценивания для библиотеки pysatl-core. Планируется создать пакет, который позволит оценивать параметры заданного семейства распределений, вычислять выборочные статистики и строить эмпирические распределения. Рассматриваются одномерные выборки независимых одинаково распределённых наблюдений.

Цель работы — реализовать пакет параметрического оценивания для библиотеки pysatl-core.

Для достижения цели предполагается разработать общий интерфейс оценивания и адаптировать к нему существующий прототип. Интерфейс должен поддерживать семейства с полностью неизвестными и частично фиксированными параметрами, исключая доступ оценивателя к сведениям о наличии, именах и значениях фиксированных параметров. Также предусматривается проверка исходных данных и ограничений модели. Результат оценивания будет содержать полученные значения, сведения о способе вычисления и диагностику численных ошибок. Архитектура должна позволять добавлять оцениватели без изменения общего механизма их вызова.

Аналитическое и численное оценивание методом максимального правдоподобия планируется перенести из прототипа в новую архитектуру. Дополнительно будут реализованы методы минимального контраста, минимального расстояния и оценочных уравнений, включая M-оценивание. Для оценивания параметров предполагается использовать обычные моменты, L-моменты и усечённые L-моменты. Байесовское точечное оценивание будет основано на сопряжённых априорных распределениях.

Непараметрическая часть пакета будет включать вычисление моментов, квантилей, порядковых и робастных статистик, а также оценивание характеристик распределения по эмпирической мере. Планируется интегрировать существующие реализации эмпирической функции распределения и ядерной оценки плотности. Выборочные статистики будут повторно использоваться в параметрических методах.

Для оценивателей и статистик предполагается реализовать параметрический и непараметрический бутстреп с воспроизводимой генерацией выборок и явным учётом неудачных повторов. Бутстреп будет применяться для получения повторных оценок и анализа их распределения. Построение доверительных интервалов и проверка гипотез в объём работы не входят.

Ожидаемый результат — расширяемый пакет оценивания с документированным интерфейсом, диагностикой и примерами использования. Корректность планируется проверить по аналитическим формулам, независимым эталонным значениям и в экспериментах на моделируемых данных. Проверки будут охватывать ограничения параметров, вырожденные выборки и неудачи численных методов. Точность оценивания и время вычислений будут сопоставлены с доступными реализациями SciPy.

По результатам работы должно быть закрыто [issue](https://github.com/PySATL/pysatl-core/issues/129).
