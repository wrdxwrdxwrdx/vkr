## Реализация пакета параметрического оценивания для библиотеки pysatl-core

Работа посвящена развитию ранее разработанного прототипа модуля оценивания в пакет параметрического оценивания для библиотеки pysatl-core. Его назначение — определять параметры выбранного семейства распределений по наблюдаемым данным и предоставлять полученную модель для дальнейшего статистического анализа.

Цель работы — реализовать пакет параметрического оценивания для библиотеки pysatl-core.

Для достижения этой цели планируется дополнить метод максимального правдоподобия методом моментов и методом минимального расстояния. Помимо самих оценок параметров, пакет должен предоставлять средства оценки их точности и построения доверительных интервалов. Предполагается использовать как асимптотические подходы, так и бутстреп. Также планируется поддержать оценивание по цензурированным данным, когда значения части наблюдений известны лишь в пределах некоторых границ.

При разработке будут учитываться особенности семейств распределений, ограничения на параметры и условия применимости методов. Планируется улучшить проверку данных и результатов, а также диагностику ситуаций, в которых получить корректную оценку не удаётся. Реализация будет опираться на существующие механизмы pysatl-core и доступные средства численных вычислений. Общий интерфейс позволит применять и сравнивать методы в рамках одной задачи.

Ожидаемый результат — пакет, объединяющий оценивание параметров, оценку их точности и обработку возможных ошибок. Его корректность и практическая применимость будут проверены в экспериментах на моделируемых данных. Планируется исследовать поведение методов при изменении объёма и характера данных, сравнить полученные оценки с известными значениями параметров и определить ограничения разработанного решения. Точность оценивания и время вычислений будут сопоставлены с доступными реализациями SciPy. Ожидается сопоставимая точность без существенного увеличения времени вычислений.
