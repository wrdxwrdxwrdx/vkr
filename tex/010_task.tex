\section{Постановка задачи}
\label{sec:task}

Цель работы~--- реализовать пакет параметрического оценивания для библиотеки pysatl-core.

Для достижения цели поставлены следующие задачи:

\begin{enumerate}[itemsep=0.5em]
    \item Реализовать дополнительные методы оценивания (полный набор методов будет известен после обзора).
    \item Реализовать средства оценки точности параметров (полный набор методов будет известен после обзора).
    \item Расширить обработку ограничений и диагностику оценивания.
    \item Реализовать оценивание по цензурированным данным.
    \item Провести экспериментальную валидацию пакета.
\end{enumerate}

В работе рассматриваются одномерные выборки независимых одинаково распределённых наблюдений при заданном пользователем семействе распределений.

План рассчитан на 2026/2027 учебный год. В первом семестре планируется выполнить задачи 1 и 3 и реализовать асимптотическую оценку точности параметров; во втором~--- завершить задачу 2 и выполнить задачи 4 и 5. Сроки являются предварительными.
